# Getting and configuring your Gemini API key

My CRM works without any AI key — every feature has a built-in equivalent generated on your
device. Adding a key simply upgrades the quality: richer analysis, better writing, and
insight text that reads like an analyst rather than a template.

---

## 1. Get a free key (2 minutes)

1. Go to **<https://aistudio.google.com/apikey>** and sign in with a Google account.
2. Click **Create API key**.
3. Choose (or create) a project when asked. The free tier is enough for personal CRM use.
4. Copy the key. It looks like `AIzaSyD…` and is about 39 characters long.

Optional: in Google AI Studio you can also **restrict the key** to the *Generative Language
API* only, which is all My CRM needs.

## 2. Add it to My CRM

1. Open **Settings → AI & Gemini**.
2. Paste the key into **API key**.
3. Pick a model:
   * `gemini-2.0-flash` — **recommended**: fast and cheap, plenty good for CRM copywriting.
   * `gemini-2.5-flash` — newer, still fast, slightly better reasoning.
   * `gemini-2.5-pro` — best quality, slower and more expensive; use it for daily summaries.
   * `gemini-flash-latest` — always points at the newest flash model.
4. Press **Save & test connection**. You should see *"Connected to gemini-2.0-flash."*
5. Check the **AI status** card at the top of the tab: *"AI ready"*.

The key is stored in this browser's `localStorage` only. It is sent to Google
(`generativelanguage.googleapis.com`) in an `x-goog-api-key` header, never in a URL.

## 3. What the AI is used for

| Feature | Data sent |
|---|---|
| Lead analysis (status, interest, priority, next action, follow-up date, reason, approach) | One lead, trimmed to the fields the AI needs. |
| AI message generator (+ regenerate / shorter / more professional) | One lead plus the current draft. |
| Daily AI summary | Your overdue/today counts, totals, and up to 6 highest-priority leads (minimum fields). |
| AI marketing insights | **Aggregate numbers only** — totals, per-course counts, source mix, follow-up delay. No names, no phone numbers, no emails. |
| Campaign messages | Course details, audience size and generic notes samples. |

**Never sent:** your whole sheet, contact lists, phone numbers, email addresses, API keys and
passwords. With *"Send the minimum lead data to the AI"* enabled (default), names are shortened
to `First L.` and long notes are trimmed to 300 characters.

### Caching keeps your quota safe

Results are cached and keyed by a signature of the lead's important fields. A lead is only
re-analysed when it actually changes, when you ask for a fresh analysis, or during the daily
summary run. Marketing insights are cached until your dataset changes.

## 4. Free tier, limits and errors

The Gemini free tier is rate limited (requests per minute and per day). My CRM handles all of
this without breaking:

| What you see | What it means | What My CRM does |
|---|---|---|
| *"Gemini is rate limiting requests right now"* | You hit the per-minute limit | Waits ~1 second and retries once; if it still fails, uses the built-in result |
| *"Your Gemini API quota is used up"* | Daily free quota finished, or no billing enabled | Falls back to built-in results until midnight Pacific time |
| *"Your Gemini API key was rejected"* | Wrong/expired key | Built-in results; fix the key in Settings → AI |
| *"This API key is not allowed to use the Gemini API"* | Generative Language API not enabled for the project | Enable it in Google Cloud, or create a new key in AI Studio |
| *"Gemini declined to answer this request"* | Safety filter blocked the prompt | Built-in result |
| *"Could not reach Gemini"* / *"You appear to be offline"* | Network problem | Everything local keeps working |

In every one of these cases the CRM stays fully usable: you still get priority scores, follow-up
categories, alerts and messages — they are just generated locally instead of by Gemini. The UI
always tells you which source was used ("Generated by Gemini" vs "Built-in message").

## 5. Production security — browser keys are not enough

Storing the key in the browser is fine for **your own laptop or phone**, where you are the only
user of that browser profile. It is **not** acceptable for a shared deployment: anyone who can
open the site's developer tools (or read `localStorage`) can copy the key and spend your quota.

Two drop-in serverless proxies are included:

* **Netlify:** `netlify/functions/gemini.mjs` (already wired to `/api/gemini` in `netlify.toml`).
* **Vercel:** `api/gemini.js` (works as `/api/gemini` automatically).

### Deploy the proxy

1. Deploy the site (Netlify or Vercel — see [`DEPLOYMENT.md`](DEPLOYMENT.md)).
2. Set an environment variable in your host's dashboard:
   * `GEMINI_API_KEY` — your Gemini key.
   * *(optional)* `GEMINI_ALLOWED_ORIGIN` — your own site origin.
3. In My CRM, open **Settings → AI & Gemini → Serverless AI proxy URL** and enter
   `https://your-site.netlify.app/api/gemini` (or `https://your-app.vercel.app/api/gemini`).
4. Remove the key from the browser field — the browser stops sending it anywhere.

The proxy receives exactly the body My CRM already sends —
`{ model, contents: [{ role, parts: [{ text }] }], systemInstruction, generationConfig }` — and
must answer `{ "text": "…" }` (a full Gemini response shape works too). No app code changes.
The included Netlify/Vercel handlers also accept a simplified `{ prompt, systemInstruction }`
body, so the same contract works from curl or an Apps Script Web App if you prefer.

## 6. Troubleshooting checklist

1. **Key starts with `AIza`?** Keys from other Google products will not work.
2. **Generative Language API enabled?** <https://console.cloud.google.com/apis/library/generativelanguage.googleapis.com>
3. **Billing/quota?** Free tier daily limits reset at midnight Pacific time.
4. **Corporate network or VPN?** Some networks block `generativelanguage.googleapis.com`.
   The CRM will keep working locally — try a mobile hotspot to confirm.
5. **Still failing?** Press **Clear AI cache** in Settings → AI, then retry. If the key works in
   [Google AI Studio](https://aistudio.google.com/)'s own playground but not here, the key is
   likely project-restricted.

## 7. Removing the key

**Settings → AI & Gemini → Remove key** deletes it from the browser immediately and switches
every feature back to the built-in assistant. Your leads are untouched.
